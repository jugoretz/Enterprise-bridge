This is the sketch that gives us the viewscreen images, cycling to the next one on press of a button.  These are all converted from GIF files (some animated) into .h arrays so the esp32 can read them directly from memory with speed and elegance.  The GIF files used in my project (see the video) are not included here--I don't own the rights to share them, necessarily.  But you can make your own.  Just get the GIF to be the exact right size using Ezgif (https://ezgif.com/) and then convert them to the c array (the .h file) using image2cpp (https://javl.github.io/image2cpp/) or your favorite tool or another method.
We also added an indicator LED when the button is pressed, just so we know that's happening.
